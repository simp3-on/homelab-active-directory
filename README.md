# Active Directory Homelab

## Overview

This repository documents my hands-on Active Directory homelab built using Windows Server 2022 and VMware Workstation Pro.

The objective is to gain practical experience with Windows Server administration, Active Directory Domain Services (AD DS), user and group management, Group Policy, and enterprise network administration.

## Lab Environment

- Host: Lenovo ThinkPad T490s
- Hypervisor: VMware Workstation Pro
- Guest OS: Windows Server 2022 Standard (Desktop Experience)
- Domain: simsi.local

- [x] Windows Server 2022 Installation
- [x] Active Directory Domain Services (AD DS)
